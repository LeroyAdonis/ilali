## T003: Create `src/lib/db/schema.ts` — Full Drizzle Schema (8 tables)

Create the complete Drizzle ORM schema for ILALI. Use `drizzle-orm/pg-core` imports. Tables:

1. **categories** — `id` (text PK), `name`, `slug` (unique), `description`, `icon` (emoji), `color` (tailwind classes)
2. **providers** — full activity listings. Includes `tags` (text array) for AI matching. `price_value` in cents (integer). `verified` boolean for trust badges. `phone` for WhatsApp. `image_url` instead of `image` for consistency. Reference categories.id as FK.
3. **venues** — physical spaces. `type` (text), `location`, `lat`/`lng` decimals, `capacity` (integer), `image_url`
4. **venue_amenities** — many-to-many. `venue_id` FK → venues.id ON DELETE CASCADE, `amenity` text.
5. **users** — auth. `role` defaults to 'parent'. Fields: name, email (unique), phone, avatar_url.
6. **provider_applications** — signup form submissions. Status: pending/contacted/approved/rejected. Fields from the ProviderApplication: name, email, phone, activity_type, description, location, age_min, age_max, price_value, image_url, status.
7. **referrals** — community referrals. referrer_name, referrer_email, provider_name, provider_email, provider_phone, status.
8. **reviews** — Phase 2 schema. provider_id FK, venue_id FK, user_id FK. rating integer, content text.

All tables with UUID defaults for primary keys (except categories which uses text slug). Timestamps with defaultNow().

## T004: Create `src/lib/db/index.ts` — Lazy-Initialized DB Client

Use the **Proxy pattern** for lazy initialization. This prevents Turbopack build failures from module-level DB init. Pattern:

```typescript
import { drizzle, type NeonHttpDatabase } from "drizzle-orm/neon-http";
import { neon } from "@neondatabase/serverless";
import * as schema from "./schema";

let _db: NeonHttpDatabase<typeof schema> | null = null;

function getDb(): NeonHttpDatabase<typeof schema> {
  if (!_db) {
    const sql = neon(process.env.DATABASE_URL!);
    _db = drizzle(sql, { schema });
  }
  return _db;
}

// Proxy that defers DB init until first query
export const db = new Proxy({} as NeonHttpDatabase<typeof schema>, {
  get(_, prop) {
    return (getDb() as any)[prop];
  },
});
```
