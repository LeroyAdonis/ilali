## Critical Pattern: DB → UI Mapping Layer

The DB schema uses different field names than the existing TypeScript types. To achieve zero UI changes, you MUST create a mapper in `src/lib/db/mappers.ts` that converts DB rows to the existing `Provider` and `Venue` types from `src/lib/types.ts`.

### Provider Mapper
DB columns to map:
- `imageUrl` → `image` (just rename)
- `priceValue` (cents integer) → `price` (formatted string: "R150" or "R2,500") and keep `priceValue` as-is
- `ageMin` + `ageMax` → `ageRange` (formatted string: "12–15 years")
- `providerName` (already correct)
- `category` (FK to categories.id — but existing type expects category NAME and categorySlug. You need to join with categories table or do a lookup. Actually, the DB `category` column IS the text ID that matches categories.id/slug. The existing `category` field in the type is the display name like "Arts & Culture" and `categorySlug` is "arts-culture". So you need to map: DB `category` = type's `categorySlug`, and you need to look up the name.)
- `distance` — not in DB. Set to `"0km"` or omit.
- `phone` — in DB, not in Provider type. Keep for WhatsApp later.

Strategy: either pass `{providers, categories}` to the mapper so it can cross-reference, OR make the page components smarter. Simplest: the mapper accepts both providers array and categories array, does the cross-reference.

### Venue Mapper
- `imageUrl` → `image`
- `capacity` (integer/null) → `capacity` (string like "50 people" or undefined)
- `amenities` — getVenueBySlug already returns `amenities` array. Good.
- `rating` — DB decimal → number. The existing type uses `number`.

## Core Mapping Function Signatures

```typescript
// src/lib/db/mappers.ts
import type { Provider, Venue } from "@/lib/types";

// DB row types (from Drizzle inference)
type DbProvider = typeof providers.$inferSelect;
type DbVenue = typeof venues.$inferSelect & { amenities?: string[] };

export function mapProvider(dbRow: DbProvider, categories: {id: string, name: string}[]): Provider {
  const cat = categories.find(c => c.id === dbRow.category);
  return {
    id: dbRow.id,
    name: dbRow.name,
    slug: dbRow.slug,
    category: cat?.name ?? dbRow.category,
    categorySlug: dbRow.category,
    description: dbRow.description,
    providerName: dbRow.providerName,
    location: dbRow.location,
    distance: "—",
    ageRange: `${dbRow.ageMin}–${dbRow.ageMax} years`,
    ageMin: dbRow.ageMin,
    ageMax: dbRow.ageMax,
    rating: Number(dbRow.rating ?? 0),
    reviewCount: dbRow.reviewCount ?? 0,
    price: dbRow.isFree ? "Free" : `R${dbRow.priceValue.toLocaleString()}`,
    priceValue: dbRow.priceValue,
    priceLabel: dbRow.priceLabel ?? "per session",
    image: dbRow.imageUrl ?? "",
    isFree: dbRow.isFree ?? false,
    featured: dbRow.featured ?? false,
  };
}

export function mapVenue(dbRow: DbVenue): Venue {
  return {
    id: dbRow.id,
    name: dbRow.name,
    slug: dbRow.slug,
    type: dbRow.type,
    location: dbRow.location,
    rating: Number(dbRow.rating ?? 0),
    reviewCount: dbRow.reviewCount ?? 0,
    image: dbRow.imageUrl ?? "",
    capacity: dbRow.capacity ? `${dbRow.capacity} people` : undefined,
    amenities: (dbRow as any).amenities ?? [],
  };
}
```
