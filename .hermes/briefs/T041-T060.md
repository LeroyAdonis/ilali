POST handler. Body: `{ query: string }`
1. Call `extractIntent(query)` 
2. If null → fallback to `searchProviders(query)` with 200 response
3. Fetch all providers
4. Score all via `scoreAllProviders()`
5. Filter out <30% score (keep them for fallback)
6. Return `{ matches: [{ provider: mapped, score, reasons }] }`
7. If all <30%: return with `fallback: true` + closest matches
