## T061: Pull Vercel Env Vars

```bash
cd /root/ilali
vercel env pull --environment=production
```

Verify critical vars are not empty:
- `DATABASE_URL` — must be the pooled connection URL
- `BETTER_AUTH_SECRET` — generate if missing: `openssl rand -hex 32`
- `BETTER_AUTH_URL` — set to `https://ilali.vercel.app` (or production URL)
- `NEXT_PUBLIC_APP_URL` — set to `https://ilali.vercel.app`
- `NEXT_PUBLIC_WHATSAPP_CONTACT_NUMBER` — can be empty (defaults to provider phone)
- `DEEPSEEK_API_KEY` — must be set for AI matching (Phase 5)

Add missing vars with:
```bash
vercel env add BETTER_AUTH_SECRET production
# etc.
```
