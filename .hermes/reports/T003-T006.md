- `providers.tags` uses `.array()` for PostgreSQL text arrays (critical for AI matching Phase 2)
- `categories.id` is `text` PK (slug-based), all others are `uuid` with `defaultRandom()`

## Concerns / Notes

1. **DATABASE_URL env var** — Required at runtime. Needs to be set in `.env.local` before `npm run dev` or `npx drizzle-kit push`. Not included here; that's an ops/seed task.
2. **`image` vs `image_url`** — Per brief, schema uses `image_url` (DB naming convention). Existing `src/lib/types.ts` uses `image`. Seed/mapping layer will need to map between them — deliberate tradeoff noted in brief.
3. **`tags` text array** — Critical for AI matching. PostgreSQL native array type. Drizzle handles this with `.array()`.
4. **Foreign keys** — `venue_amenities`, `reviews` use ON DELETE CASCADE. `users` FK on reviews has no cascade (don't delete reviews when user is deleted). `providers.category` references `categories.id` with RESTRICT (default).
5. **No separate migration file yet** — `drizzle-kit generate` needs a DB connection to produce SQL migrations. Schema is ready for that step.
