## T009: `src/lib/db/seed.ts` — Seed Script

### Created
- `src/lib/db/seed.ts` — Drizzle ORM seed script for the live Neon database.

### What it does
- Reads source data from `src/lib/constants.ts` and inserts into Neon PostgreSQL via Drizzle ORM.
- Uses `onConflictDoNothing` for idempotent re-runs (safe to run multiple times).

### Data seeded

| Table | Count | Details |
|---|---|---|
| `categories` | 11 | All from constants.ts, with id, name, slug, description, icon, color |
| `providers` | 4 | All mapped with tags, featured/isFree flags, verified=false, phone/lat/lng=null |
| `venues` | 4 | Capacity strings parsed to integers (50, 30, null for "100+", 40) |
| `venue_amenities` | 16 | 4 amenities each for all 4 venues |

### Field mappings applied
- `constants.image` → `schema.imageUrl`
- `constants.categorySlug` → `schema.category` (FK to categories.id)
- `constants.featured` / `isFree` → schema fields (provider 2 featured=true, provider 4 isFree=true)
- Tags added per brief: 4-5 tags per provider for AI matching
- `priceValue` preserved in cents (150, 2500, 1500, 0)
- Capacity: `/\d+$/` regex extracts integer or returns null for non-numeric ("100+ people" → null)

## T011: `src/lib/db/queries.ts` — Query Functions

### Created
- `src/lib/db/queries.ts` — 7 async query functions using Drizzle ORM.

### Functions implemented

| Function | Behavior |
|---|---|
| `getCategories()` | Returns all 11 categories ordered by name |
| `getProviders(filters?)` | All providers with optional category, ageMin, ageMax, location, maxPrice filters |
| `getProviderBySlug(slug)` | Single provider by slug; returns `null` if not found |
| `getVenues()` | All 4 venues ordered by name |
| `getVenueBySlug(slug)` | Single venue + amenities array; returns `null` if not found |
| `searchProviders(query, filters?)` | Case-insensitive `ilike` across name, category, providerName, location; optional filters |
| `getSimilarProviders(providerId, limit=3)` | Tag overlap via PostgreSQL `&&` array operator, excludes self |

### Query patterns used
- `db.select().from(table).where(...)` — standard Drizzle select
- `eq()`, `ilike()`, `and()`, `or()` — Drizzle operators
- `sql` raw templates for `>=`/`<=` numeric comparisons and `&&` array overlap
- `sql.raw()` for PostgreSQL array literal construction (tags overlap)
