## T022 ✅ — `src/lib/validations.ts`

Created Zod validation schemas:

- **`providerApplicationSchema`** — validates name (2-100 chars), email, phone (`+27 XX XXX XXXX` regex), activity_type, plus optional: description, location, age_min/max (0-18 int, nullable), price_value (int ≥0, nullable), image_url
- **`referralSchema`** — validates referrer_name, referrer_email, provider_name, provider_email, provider_phone (optional)
- Exports `ProviderApplicationInput` and `ReferralInput` types

## T023 ✅ — `src/lib/suburbs.ts`

Created CT suburb list with 61 Cape Town suburbs as a `const` assertion array. Includes all required suburbs plus extras (Kalk Bay, Mowbray, Harfield Village, Brooklyn) to reach ~60. Exports `CTSuburb` type.

## T024 ✅ — `src/lib/utils.ts`

Created `formatPhone(value: string): string` — strips non-digits, ensures `+27` prefix (handles `0XX`, `27XX`, `+27XX` formats), formats to `+27 XX XXX XXXX`. Returns partial formatting for incomplete input so users see real-time formatting.

## T025 ✅ — `src/lib/rate-limit.ts`

In-memory Map-based rate limiter:
- `checkRateLimit(key, maxRequests, windowMs)` — returns `false` when limit exceeded
- `getRateLimitReset(key, windowMs)` — returns seconds until reset
- Auto-cleanup of stale entries every 5 minutes via `setInterval`

## T026 ✅ — `src/app/api/providers/apply/route.ts`

POST handler:
1. Extracts client IP from `x-forwarded-for` / `x-real-ip` headers
2. Rate limits: 5 requests per IP per hour (returns 429 with `Retry-After` header)
3. Parses JSON body, validates with `providerApplicationSchema`
4. Returns 400 with `{ errors: fieldErrors }` on validation failure
5. Inserts into `provider_applications` table (Drizzle) with `status: "pending"`
6. Returns 200 `{ success: true }` on success, 500 with error message on DB failure

## T027 ✅ — `src/app/api/referrals/route.ts`

Same pattern as apply route:
1. Rate limit check (shared store)
2. Validates with `referralSchema`
3. Inserts into `referrals` table with `status: "pending"`
4. Proper error responses (400, 429, 500)
