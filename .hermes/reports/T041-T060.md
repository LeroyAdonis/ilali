## Phase 5C: AI Matching Engine (T046-T051)

### T046 — AI Intent Extraction (`src/lib/ai/match.ts`)
- `extractIntent(query)` calls DeepSeek API (`deepseek-chat` model)
- System prompt includes full tag vocabulary (16 tags) + 61 CT suburbs
- 3-second timeout via AbortController
- Graceful fallback: returns `null` on any failure (bad API key, timeout, bad response)
- Cleans markdown fences from LLM response before JSON.parse
- Normalizes tags to only valid entries from MATCH_TAGS
- Converts priceMax from rand to cents

### T047 — Scoring Algorithm (`src/lib/ai/score.ts`)
- `scoreProvider(provider, intent)` — per-provider scoring (0-100):
  - Tag overlap: up to 40 points
  - Age range overlap: up to 25 points (linear ratio)
  - Location partial match: up to 20 points
  - Price within budget: up to 15 points
- `scoreAllProviders()` — scores all, sorts descending
- Returns `{ score, reasons[] }` for each

### T048 — Match API (`src/app/api/match/route.ts`)
- POST handler: `{ query: string }`
- Flow: `extractIntent()` → `getProviders()` → `scoreAllProviders()` → filter <30%
- High-score matches return as `{ mode: "ai", matches: [...] }`
- All <30% → returns as `{ fallback: true, matches: closestResults }`
- LLM failure → keyword fallback via `searchProviders(query)`

### T049 — Natural Language Mode in SearchBar
- NL detection: input contains spaces AND >20 characters
- NL mode changes placeholder to "Describe what you're looking for..."
- NL mode shows Sparkles icon, tints border ilali-300
- On submit with NL: sets `nl` param → `/browse?nl=...`
- Regular short queries use `q` param as before

### T050 — Match Results on Browse Page
- BrowsePage detects `searchParams.nl`
- Server-side fetches `POST /api/match` with the query
- Passes `matchResults` to `ResultsSection`
- AI results shown with "🤖 AI-powered results" label
- ProviderCard accepts `matchScore` and `matchReasons` props
- Match badges: 80%+ gradient teal, 60%+ solid teal, <60% slate
